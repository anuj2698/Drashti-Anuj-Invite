# Anuj & Drashti Wedding Invitation

A mobile-first wedding invitation website for Anuj and Drashti.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.


## Pages

- `index.html` — English invitation
- `gujarati.html` — Gujarati invitation

Each page is fully static; edit copy directly in the HTML of each page. There is no language toggle, so share the link to the page you want.
